# drama-game

## 《雷雨：门外》（暂定名）

一款以《雷雨》为蓝本、以四凤为主视角的探索式叙事独立游戏。

> 今天，你准备和爱人离开。  
> 天亮之前，你必须重新决定，自己要怎样活下去。

**当前阶段：剧情与视觉设计初稿 v0.1，持续打磨中。**

本仓库目前用于保存和迭代剧情、游戏设计与美术需求。现有文档尚不是完整的逐场对白剧本，也没有可运行的游戏、已完成的概念图或正式美术资产。标题、分支、结局、体量、视觉路线与具体实现均仍可讨论。

## 当前创作核心

不是把家族秘密做成一道血缘推理题，而是让玩家先认真地替四凤安排明天，再经历原有生活计划的崩塌，并重新决定她如何继续生活。

> 那段爱情不能继续，但我喜欢过的颜色，不需要一起消失。

视觉围绕门、人物距离、手部动作、箱子与衣物展开，让两次收拾行李共享物件和空间，却呈现不同的选择与意义。

## 原型与美术验证范围

剧情初稿的可玩原型目标仍为约 30—45 分钟，只保留四凤、侍萍、周萍三位角色，以及周宅后廊和鲁家房间两处主要空间。

美术需求中的 **P0** 服务这两处空间、三位角色及核心互动的概念验证；**P1** 才扩展送药空间与繁漪、周朴园、周冲；其他角色、场景和结局画面列为后续增补。概念稿、动作测试和可导入游戏的生产资产分别验收，不混为一谈。

当前优先测试手绘舞台式 2D，但保留剧情初稿中的像素路线。先以同一个鲁家房间、同一机位和同一次折衣动作做对比样张，再决定，不把视觉建议自动视为已经定案。

## 后续打磨

保留剧情初稿作为讨论基线，逐步完善人物动机、四幕之间的因果、玩家选择与结局条件，并把关键场景展开为具体动作、对白和互动。视觉工作先从鲁家房间的灰阶布局与风格对比开始，再推进角色、空间、UI 与两次收拾的演出。

暂不引入引擎、代码框架或实时生成对白系统，也不提前批量制作完整版美术。

文档直接在本仓库中迭代，历史版本由 Git 保存；新增设想应明确区分“待讨论”与“已决定”，不把初稿中的建议自动视为最终制作要求。剧情与视觉提案出现差异时，先记录并确认，再同步更新对应文档。

## 原作与授权

本项目仍需核实《雷雨》的改编授权及发行范围；保存创作初稿不代表已经取得授权。初稿文末保留了原讨论中的参考资料与风险提示，正式制作前还需回到选定的原作版本核对。

视觉参考、字体、照片和其他素材的来源及可用范围也需记录；文档中的设计示例不代表相关资料已经完成收集或权利核查。
