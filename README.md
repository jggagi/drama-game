# drama-game

## 《雷雨：门外》（暂定名）

一款以《雷雨》为蓝本、以四凤为主视角的探索式叙事独立游戏。

> 今天，你准备和爱人离开。  
> 天亮之前，你必须重新决定，自己要怎样活下去。

**当前阶段：创作初稿 v0.1，持续打磨中。**

本仓库目前用于保存和迭代剧情与游戏设计。现有文档是剧情大纲与玩法提案，尚不是完整的逐场对白剧本，也没有可运行的游戏。标题、分支、结局、体量与具体实现均仍可讨论。

## 从这里开始

[阅读《雷雨：门外》剧情与游戏设计初稿](docs/story-design.md)

初稿包含创作定位、改编边界、八位人物的写作方向、三个核心互动机制、四幕剧情、两次收拾行李的关键场景、三个结局方向，以及小体量可玩原型的设计目标。

**含《雷雨》核心剧透。** 新增台词、桥段、互动和结局分支属于改编提案，不是原作文本。

## 当前创作核心

不是把家族秘密做成一道血缘推理题，而是让玩家先认真地替四凤安排明天，再经历原有生活计划的崩塌，并重新决定她如何继续生活。

> 那段爱情不能继续，但我喜欢过的颜色，不需要一起消失。

## 后续打磨

先保留这版初稿作为讨论基线，逐步完善人物动机、四幕之间的因果、玩家选择与结局条件，并把关键场景展开为具体动作、对白和互动。暂不引入引擎、代码框架或实时生成对白系统。

文档直接在本仓库中迭代，历史版本由 Git 保存；新增设想应明确区分“待讨论”与“已决定”，不把初稿中的建议自动视为最终制作要求。

## 原作与授权

本项目仍需核实《雷雨》的改编授权及发行范围；保存创作初稿不代表已经取得授权。初稿文末保留了原讨论中的参考资料与风险提示，正式制作前还需回到选定的原作版本核对。
