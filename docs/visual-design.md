# 《雷雨：门外》——视觉设计初稿

> 版本：v0.1  
> 建档日期：2026-10-03  
> 状态：待评审的视觉提案；不是已批准的美术定稿或生产规格。  
> 剧情基线：[剧情与游戏设计初稿](story-design.md)，本次对照版本 `4b9214e06b7916bf14257ad171984e7355f22e7b`。

## 1. 视觉方向声明

> 以潮湿、克制、写意化的室内戏剧，表现家庭权力、秘密与出走。让门、距离、手部动作和普通衣物承担叙事；让玩家看见四凤如何从替别人做事，逐渐转向为自己作决定。

画面应首先回答三个问题：**谁能决定这个空间如何使用？四凤现在能够去哪里、与谁说话？同一件物品为什么在真相以后改变了意义？**

这不是一套泛化的“民国复古”装饰。服饰和家具提供可信的生活背景，但不应挤占人物与动作的注意力。视觉也不能从开场起就宣布所有温柔都是假的：玩家必须先相信那件新衣、那次私下交谈，以及她正在准备的明天。

### 四条设计原则

| 原则 | 具体表现 | 失效征兆 |
| --- | --- | --- |
| 空间有社会关系 | 门口、主座、过道和人物距离影响谈话与通行 | 场景漂亮，但玩家看不出谁在场、谁挡住去路 |
| 压抑不等于看不清 | 用遮挡、构图和冷暖关系制造压力，保留人物、手和出口的可辨识度 | 全屏暗黄、黑脸、找不到可互动物 |
| 普通生活先于悲剧象征 | 衣物先是喜欢的衣物，箱子先是能装东西的箱子 | 每件物品都像预告死亡的道具 |
| 选择通过动作发生 | 举着、放下、收回、让开、自己折好 | 高潮只剩长篇文字或不可操作的插画 |

人物曾经的温柔可以是真的，后来造成的伤害也可以是真的。视觉不要替玩家提前把任何人判成单一符号。

## 2. 方案状态：保留像素路线，先验证手绘舞台路线

剧情初稿提出“小比例像素人物、固定镜头室内场景和少量关键插画”；后续视觉讨论提出“舞台式手绘 2D 场景、探索人物、按需肖像和关键插画”。**两者存在待解决的风格差异，本文不自动覆盖剧情初稿。**

| 方向 | 当前用途 | 需要验证的事情 |
| --- | --- | --- |
| A：手绘舞台式 2D | 本轮优先测试的视觉假设 | 小比例人物动作是否清楚；背景、肖像与手部特写是否统一；分层与修改成本能否承担 |
| B：像素化固定镜头 | 保留的比较路线，不淘汰 | 同样动作能否用轮廓、姿态和节奏表达；衣物与空间细节能保留多少；实际生产是否更适合团队 |
| 纯视觉小说或完整 3D | 当前不作为首轮验证对象 | 不是断言其不可行，而是暂不扩大表现形式与工具链 |

比较方法：用**同一个鲁家房间、同一机位、同一角色站位和同一次折衣动作**做低保真 A/B 样张。只做足够判断的样张，不为两条路线分别生产完整资产。比较情感表达、空间可读性、人物一致性、动画工作量和修改难度；不能仅凭“哪张静帧更精致”决定。

路线获确认后，再同步更新剧情初稿的“基本形态”与本文件版本。批准之前，不把分辨率、绘制软件、动画方法或游戏引擎锁死。

## 3. 画面形态与镜头

### 3.1 默认探索画面

采用固定或小幅平移的房间镜头，先测试略带俯角的浅三分之四视角：能够看清地面通路、门的位置和人物双手，又不把角色缩成地图标记。不是大俯视地图，也不是只能左右移动的一条平面线。

房间由前景遮挡、中景行动区、后景门窗组成。可探索场景必须有一张附带行动区与遮挡标注的草图；只有气氛图不能视为场景设计完成。

以 `1920 × 1080`、`16:9` 为首轮版式测试基准，另做 `1280 × 720` 可读性检查。人物在常用机位中暂以画面高度约 `20%—28%` 测试；这是构图参考，不是所有房间的强制比例。镜头尺寸与角色身材比例是两件事，角色不默认采用幼态大头造型。

进入对话时尽量保留人物原来的空间位置。半身肖像按情绪需要出现，不必每句都弹出，也不应长期用两张巨大立绘盖住门和第三位在场者。

### 3.2 镜头只在必要时靠近

常规镜头承担走动、观察、安排会面与在场关系。中景承担递信、端药和改变人物距离。物件近景承担两次收拾行李等需要看清手部的行动。全屏关键插画只用于少数停顿或过渡，不代替本应由玩家完成的选择。

近景前后保留明确的空间连续性：谁在旁边、物品放在哪里、门是否开着，不随切镜悄悄变化。切回探索画面时，人物与物品状态应与玩家刚完成的动作一致。

### 3.3 视觉不能越过四凤的知识边界

不显示隔墙人物轮廓、隐藏的“偷听人数”、全宅实时人物地图或未经揭露的关系图。可见人物、脚步字幕与视线反应可以提供线索，但必须来自当前角色能够感知的内容。

关门会改变视线和空间状态，**不自动等于安全保密**。具体能否被听见由叙事条件决定；美术不能用绿色盾牌或“无人偷听”提示作出剧情未授权的保证。

人挡在门口时，应让玩家看见是人的阻拦，而不是一条莫名其妙的碰撞墙。

## 4. 空间设计：两处原型空间，一处扩展验证空间

### 4.1 周宅后廊／门厅——能经过，不等于能停留

首轮空间为周宅服务通路与内室之间的交界。较重的门框、整齐的家具边缘与通向另一处生活的侧向出口，把人物分成不同的距离层次。

构图优先显示三件事：四凤从哪里进入、谈话可以在哪里暂时停下、其他人可能从哪个可见入口出现。门框可以分隔两个人，但不能遮住正在进行的手部互动。

这里也要容纳温柔：一次短暂独处可以发生在普通的过道里，不必突然换成柔光恋爱海报。视线、让路和小动作足以改变气氛。

需要验证白天／闷热与傍晚两个光照状态；空间结构不随情绪变化而重新排列。具体建筑样式、宅邸平面与年代细节仍待原作版本和美术考据确认。

### 4.2 鲁家房间——生活有限，但不是生活的废墟

这是首轮情感核心：床、桌、坐具、存放衣物的位置，以及一只可使用的旧箱子。物件不多，但要让人看出有人整理、修补、使用它们。

房间可以拥挤，却不以污渍、破洞和倾斜墙面把贫穷画成猎奇布景。这里既有日常照料，也有母女冲突，不是与周宅对立的天然和睦避难所。

两次收拾行李必须沿用同一机位与主要空间结构。变化来自光线、人在不在、手伸向哪里、衣服由谁收好，以及箱子里保留了什么。不能把第二次场景随意改成灾难现场来制造“更悲伤”的效果。

### 4.3 周宅内室／送药空间——体面如何要求他人服从

作为下一阶段的扩展概念空间，测试繁漪、周朴园与四凤的三角站位。视觉重点是主座、送药路径、可放下托盘的位置和能够退出的门。

不因“繁漪房”的方便称呼，擅自决定送药发生在她的私人卧室。最终房间名称与人物位置须跟随后续逐场剧本。空间要漂亮而受约束，不做阴森宫殿或欲望奇观。

**这一空间不是三人、两场景原型的前置资产。** 完整版的六到八个区域也不在本轮批量制作。

## 5. 视觉母题与使用规则

| 母题 | 叙事作用 | 使用规则 |
| --- | --- | --- |
| 门与门槛 | 通行、拒绝、邀请、自己选择去向 | 门的开闭、人物站位与可行动路径一致；正门结尾不依赖金光或胜利特效 |
| 窗与窗外光 | 看得见但尚未抵达的世界 | 不直接把窗外画成幸福天堂；保留雨、树影和远处生活的存在 |
| 箱子、新衣、针线 | 愿望在关系破裂后仍可能属于自己 | 同一物品跨画面保持结构、颜色基底和磨损位置；不偷偷换成另一件衣服 |
| 托盘、药碗、信件 | 命令与承诺通过人的手传递 | 接触点、重量感与接收者反应比花纹更重要 |
| 雨、潮气与电光 | 外部天气进入既有生活秩序 | 雨默认在室外；室内渗漏需有具体叙事依据，不自动把所有房间画成水灾现场 |

道具具有功能，再逐渐获得象征意义。不要反复用镜头和音效告诉玩家“这件东西非常重要”。

## 6. 色彩脚本

### 6.1 四幕与尾声的色彩进程

| 段落 | 主色关系 | 情绪任务 | 需要保留的例外 |
| --- | --- | --- | --- |
| 第一幕：闷热 | 旧木褐、灰绿、偏暖墙面；光线受阻但不昏黑 | 有生活温度，也有不流通的空气 | 周萍与四凤的片刻温柔不能被恐怖化 |
| 第二幕：来客 | 室内暖色与门外灰蓝交错，门框形成更多分割 | 显示距离、进出与关系压力 | 鲁家不自动套上“安全的暖黄滤镜” |
| 第三幕：第一声雷 | 蓝灰进入原有暖色，局部反差提高 | 熟悉空间正在失去稳定 | 真相停顿时，脸、手和出口仍然可辨 |
| 第四幕：暴雨 | 深蓝灰、潮白、少量稳定的室内暖点 | 让人物必须重新决定下一步 | 不用把新衣变成死灰来象征爱情消失 |
| 尾声：雨后或暂住 | 低饱和浅光与普通物件的自然色 | 留出继续生活的空间 | 不使用金色通关滤镜暗示问题全部解决 |

### 6.2 起始色票：供样张试色，不是定稿

| 用途 | 起始色值 | 注意事项 |
| --- | --- | --- |
| 周宅旧木 | `#4B3830` | 大面暗部需要结构变化，不能一块黑褐 |
| 暖灰空气／旧墙反光 | `#B6A27F` | 不做覆盖全画面的黄色滤镜 |
| 鲁家墙面 | `#C9C2AE` | 与布料、皮肤拉开材质差异 |
| 四凤日常衣物候选 | `#85998F` | 不是以绿色编码善良 |
| 门外雨前灰蓝 | `#5A6C7A` | 与皮肤分离，保持轮廓 |
| 雨夜深部 | `#25323E` | 出口与互动区仍需可辨 |
| 电光／雨面反光 | `#D7E0DF` | 局部使用，不以全屏爆闪制造刺激 |
| 纸页 | `#E9E2D2` | 纹理不能影响阅读 |
| 纸页正文 | `#2D3032` | 优先可读，不模拟褪色到看不清的墨迹 |
| 新衣试色 | `#AB7C70` | 低饱和暖色候选；最终可换，但必须保持跨场景一致 |

新衣不必是红色、婚服或恋人赠品。色票只是帮助验证“她确实喜欢这个颜色”。确定后记录基础色与灯光下的表现，不能用后期调色改变它的身份。

所有关键状态同时依靠文字、轮廓或布局表达，不仅依靠颜色。色弱、灰度与低亮度检查属于样张验收，不等于本轮已通过这些检查。

## 7. 角色视觉方向

采用适度写意的身体与面部比例。四凤虽年轻，不画成儿童化、卖萌化的形象；所有人物都避免使用身体外形来代替道德判断。角色的工作与社会位置更多体现在衣料、保养方式、动作习惯及其如何占据空间。

| 角色 | 轮廓、服装与材质 | 动作与表情重点 | 避免 |
| --- | --- | --- | --- |
| 四凤 | 利落的日常劳动衣物；洗过、修补过，但有自己的整理习惯；新衣单独设计 | 做事快；与人冲突时可能先收住动作；后期能够自己完成一个动作，而不是突然换成英雄姿势 | 破碎感美少女、洁白圣女、用妆容或腹部特写泄露剧情 |
| 侍萍 | 耐穿、整洁、反复使用的衣物；手与肩颈体现劳动，但不夸张老化 | 先看女儿再回应他人；想替她收拾又停住；克制与强硬都成立 | 只剩苦相、持续哭泣、蓬乱化或失控奇观 |
| 周萍 | 体面、受教育的青年；衣料与剪裁比四凤更精细，但不靠珠宝炫耀 | 私下会留意四凤；面对要求时视线和身体可能后撤；温柔与逃避可以在同一张脸上 | 一眼反派、邪笑、用“帅”替代具体人格 |
| 繁漪 | 质量较好的衣料、较清晰的轮廓；深绿或酒红仅是试色，不是善恶编码 | 长时间静止与突然靠近的反差；疲惫、警觉、受伤和锋利都可表达 | 妖艳疯女人、过度裸露、永远冷笑的女反派 |
| 周朴园 | 稳定、整洁、克制的深色轮廓，细节有维护 | 很少需要大动作；别人调整位置，而他不必起身 | 怪物化、不断怒吼、靠极端脸部阴影证明邪恶 |
| 周冲 | 学生气、相对轻快的衣着；与周萍有年龄与姿态区分 | 更常探身、移动、望向窗外；愿意帮助与不懂边界可以并存 | 小丑化、恋爱备胎标签、幼儿化 |
| 鲁大海 | 户外劳动相关的粗布与使用痕迹；结实不等于夸张肌肉 | 动作明确、身体向前；面对家人也能有柔软停顿 | 暴力莽汉、脏污等于真实、只为护送妹妹存在 |
| 鲁贵 | 努力维持体面、熟悉宅门规矩的外观 | 对上与对下的姿态差异、接话前的观察 | 丑角化、用肥瘦或面貌直接编码贪婪 |

原型优先四凤、侍萍、周萍。下一阶段再加入繁漪、周朴园、周冲，最后扩充鲁大海和鲁贵。角色年龄、服饰称谓和具体年代制式应随选定原作版本核对，本稿不替代这项工作。

四凤的变化主要通过动作主动性、站位和停顿呈现，不通过“更漂亮、更华贵、更像恋爱女主”表达成长。

## 8. UI：纸面感服务阅读，而不是妨碍阅读

### 8.1 明日清单

清单是一张会被补写、划去、折叠的纸，不是奖励任务栏。它区分“别人说会安排”“已经落实”“尚未决定”，但不暴露隐藏结局条件。

在剧情未确认四凤书写能力之前，不把大量流畅长句强行画成她的亲笔。纸上可以使用短词、数字、记号和简短条目；完整可读句作为面向玩家的界面转写层。是否存在代笔等情节，留给剧本决定，不由 UI 擅自补设。

真相后，只有确实失效的安排被划去。已经取得的工钱、她的衣物与其他仍成立的安排保留。旧记录可以回看，不以一键清空来制造情绪。

### 8.2 对话与选择

对白采用清晰的中文屏幕字体，姓名、正文与选择区保持稳定层级。手写质感只用于标题、短注和纸面记号，不作为长篇正文的唯一呈现方式。字体具体选型与使用权限待确认，不随文档提供字体文件。

选择项写出实际行动，例如“请娘到后廊再说”“现在请周萍过来”“我先不回答”，不标注善恶、好感增减或最佳答案。沉默也是可见选项，不要求玩家等过一个隐藏时限。

肖像和文本面板不能遮住关键人物、手和门。必要时更换对话版式或留出安全区，不靠把字缩得很小解决。

### 8.3 物品、提示与输入

物品界面应能追踪物品身份与去向，而不是鼓励收集。拿起、展开、放回、装入箱中都应有明确反馈。关键选择不以精准拖拽或快速点击为唯一输入方式。

互动提示用稳定而克制的轮廓、光标或短文字。提供主动显示可互动点的方式，避免在暗色背景里逐像素寻找热点。对于尚未可用的行动，只解释四凤已经知道的原因。

### 8.4 首轮可读性与舒适性目标

默认以 1080p 下约 26—30 px 的对白字号测试，并在 720p 下实看；字号可放大到至少默认值的 150%，放大后允许重排或滚动，不直接截断文本。此处是原型目标，不是已经实现的功能。

同时准备弱化闪光、关闭镜头抖动和减少动态背景的方案。雷声、脚步等关键听觉线索要有可选文字提示，不让关闭闪光或静音的玩家丢失必要剧情信息。字幕不能把“听见脚步”擅自升级成“某人正在偷听”。

## 9. 关键演出：第二次收拾行李

### 9.1 两次必须共享的东西

同一个房间，同一只箱子，同一件新衣，同一套物品放置逻辑。第一次玩家形成的物品选择，应在第二次得到继承；没有带上的针线包不能凭空出现在箱内。

场景状态至少区分物品在屋内、手中、箱内或已交给他人。这里只提出叙事连续性要求，不规定引擎与存档结构。

### 9.2 成对的动作节拍

| 节拍 | 第一次收拾 | 第二次收拾 |
| --- | --- | --- |
| 看见箱子 | 箱子承载两个人谈过的将来 | 箱子仍然能装东西，计划却需要重写 |
| 拿起新衣 | 可以想象穿上的生活；动作轻快但不夸张 | 先停一下，再允许玩家决定如何处理 |
| 母亲伸手 | 准备帮忙，可能带着催促或管束 | 仍想帮忙，但有机会在四凤回应后停住 |
| 折衣 | 玩家第一次熟悉这个动作 | 重复动作，重心从“和谁走”转向“我留下什么” |
| 放进箱子 | 是共同计划的一部分 | 可以是四凤自己的选择，不要求台词先宣告成长 |
| 合上箱子 | 离期待更近 | 不代表和解完成，只代表下一步可以开始 |

“这件是我自己挑的”可以出现在保留新衣的分支，但不能强迫所有玩家做同一选择来证明成熟。其他处理方式也需有尊重人物的演出，不赋予偷偷扣分的道德含义。

### 9.3 关键插画的边界

首选“母亲的手已经停住，四凤正在自己折衣”这一时刻，而不是哭泣面孔的特写。插画保留手、衣物、箱口、坐具和人物距离；不添加拥抱大和解、第三人背影或婚礼象征。

母亲在场的构图只用于对应分支。若她不在场，不允许为了复用插画把她自动搬回房间；其他分支可以保留原有房间镜头，避免无意义地增加大量 CG。

无论是否使用插画，拿起、处理和放入衣物的关键行动仍交还玩家。不要在最重要的一幕用一张图把互动全部带过。

## 10. 动画与天气：把预算给接触动作

优先验证门的开闭与停步、端起与放下、拿衣与折衣、递出与收回、坐下与起身。角色要对重量、障碍物和对方的动作作出反应。衣服不能穿过箱壁，药碗不能漂浮，手不能只是贴在物品旁边。

探索移动可以简化，但涉及双手与道具的近景不宜未经验证就机械复用全身移动动画。逐帧、骨骼或局部替换的最终选择留到样张测试之后。

雨水、树影与窗帘提供局部动态即可。人物停顿不需要全屏震动来强调。电光要稀少、可弱化，并用持续光照变化或文字线索保留叙事效果。

结局中的死亡不以写实伤害特写、反复回放或视觉奇观处理。可以使用空房间、未收完的物品和被中断的动作承接余波。

## 11. 制作范围与验证顺序

| 阶段 | 目的 | 视觉范围 |
| --- | --- | --- |
| P0：首轮概念验证 | 判断风格与核心动作是否成立 | 两个空间、三位角色、色彩脚本、核心物件、UI 草图及两次收拾的对照分镜 |
| 原型生产授权后 | 服务剧情初稿的 30—45 分钟缩编原型 | 只将已认可的必要概念转成可导入资产、交互状态与动作测试 |
| P1：扩展视觉提案 | 验证周家的权力场景与六人视觉关系 | 加入送药空间及繁漪、周朴园、周冲；不是默认立即制作 |
| P2：完整版扩展 | 随逐场剧本补齐需求 | 鲁大海、鲁贵与其他场景、结局插画；另行确认 |

先做可修改的灰阶构图，再做风格 A/B 样张，之后确定角色与色彩，最后验证 UI、动作和成对情感场景。不要先精绘完整房间，再发现没有地方放人物、对白框或可交互物。

“最小视觉包”是用于判断方向，不是完整游戏已经完成的证明。具体数量、交付格式、命名与验收问题见配套 Brief。

## 12. 待决定事项与评审门槛

| 待决定事项 | 需要的证据 | 在此之前不做什么 |
| --- | --- | --- |
| 手绘还是像素 | 同构图样张、实际尺寸观看、同一动作试作及修改记录 | 不采购整套不兼容资产，不锁定全项目生产方式 |
| 年代与居住环境的具体样式 | 选定原作版本、服饰和室内资料来源记录 | 不把泛化的老上海广告、装饰艺术或古宅元素混搭成既定史实 |
| 新衣款式与颜色 | 两次收拾的对照测试；身份一致且有普通生活吸引力 | 不自动设计成婚服或象征纯洁的白裙 |
| 肖像使用频率 | 对话场景是否仍能读懂在场关系 | 不预订全员大量表情立绘 |
| 插画与互动如何衔接 | 关键动作能否由玩家完成，切镜是否保持状态 | 不把核心场景改成不可操作的长过场 |
| 资产生产与预算 | 概念批准、原型动作表、合作方报价与返修边界 | 不把概念图数量等同于可导入游戏资产数量 |

首轮评审要实际检查：关闭文字以后，是否能看见人物正在做什么；缩小画面以后，是否还能区分门、手和物件；两次收拾是否确实是同一场景；关闭闪光以后，是否仍能跟上剧情；不读人物标签，是否也没有靠脸谱暗示谁好谁坏。

**最后的判断不是“是否足够复古”，而是玩家能否记住：同样一件衣服，第一次是为了和一个人离开，第二次仍然可以为了自己带走。**
